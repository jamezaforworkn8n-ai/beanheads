Privacy Policy — Beanheads Uploader

Effective date: 20 November 2026

What this app is

Beanheads Uploader is a private tool run by the owner of the Beanheads channel. It uploads the channel's own videos to the owner's own YouTube channel, and sets their titles, descriptions and scheduled publish times, using the YouTube API Services. It is not offered to the public, and it has no other users.

Data it accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube upload permission only to upload Beanheads videos and their text to the owner's channel. It does not read, collect or store data about any other person, and it does not access viewers' data.

Storage and sharing

The access token Google issues is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Revoking access

The permission can be removed at any time at myaccount.google.com/permissions.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions: message the Beanheads Facebook page.
